# ddlcmod

An original fan-made DDLC-compatible mod starter with a large collectible literary-fragment system.

## What's included

- A playable opening and clubroom loop.
- Multiple choices and simple progression variables.
- A 1,000-entry collectible fragment collection generated from original text.
- Collection progress tracking.
- Secret-page and reading routes.
- No original DDLC game files or copyrighted assets are included.

## Install

1. Install a legally obtained copy of a DDLC-compatible game.
2. Download or clone this repository.
3. Copy `game/ddlcmod_main.rpy` into the game's `game/` directory.
4. Launch the game.

## Development

The 1,000 fragments are created from 10 themes × 10 locations × 10 motifs. This keeps the repository small while still giving the player 1,000 distinct collectible entries.

This repository is a fan project and is not affiliated with Team Salvato.
